XCPETS pet generator

Block hash (+ optional pet id / hatch tx hash) → SHA-256 → sfc32 PRNG → traits → 32×32 pixels. Deterministic: anyone can re-derive any pet. Same generation rules as the XCPETS CLI: every seed gives the same pet, pixel for pixel.

Species/Tier overrides are previews only. Real pets always use the rolled values.
